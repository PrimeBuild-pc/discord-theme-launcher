THEME STUDIO / DISCORD THEME LAUNCHER 0.3.0-beta.8 - WINDOWS X64

1. Extract the ZIP. Run DiscordThemeLauncher.exe normally, not as Administrator.
   The interface is English by default. Italian, Spanish, Russian and German are in the
   header language menu. These instructions stay in English.
2. Create starts in neutral Fluent Dark with no server selected. Choose your
   server ID / Discord channel link. Community offers four credited designs,
   including Zenit Gold -- by JACKPOT71, and downloaded .theme.css import.
   Review compatibility/resources before accepting. Unsupported CSS is rejected.
3. Use Style and Artwork to customize. Editing stays in preview by default.
4. Save or Share theme to keep a .dtheme file with its selected assets/licenses.
5. Click Apply to Discord. Review the theme and server in the overlay.
6. Finish calls/streams and save drafts, then choose Continue & apply.
   Discord restarts only after this confirmation. Back to preview / Esc cancels.
   Missing Vencord setup is offered in the same overlay with explicit consent.

There is no separate preview-only product mode or external restart checkbox.
A disabled Apply means the configuration/preview is not ready or an operation
is running. A blocked Continue explains an unsupported environment or asks
for consent to the offered official Vencord setup. Do not bypass these checks.

Changes affect your LOCAL CLIENT. Other members must adopt a shared theme
themselves. No token, login, bot, Nitro, server permissions or credentials.
The launcher never joins servers, reads messages or changes server settings.

One personal theme is active at a time. Apply replaces that slot and disables
a bundled theme targeting the same server. Other server presets remain enabled.
Disable personal theme removes the slot. Restore previous setup recovers the
last managed files/enablement; the restore is itself reversible.

Recovery > Open original presets opens the previous multi-server setup. Applying that selection
replaces the personal slot too and removes unchecked bundled themes. Unrelated
themes, plugins, QuickCSS, online theme links and preferences are preserved.

The EXE embeds verified preset CSS/fonts/artwork. Vencord users can configure
offline. Optional upstream Vencord installation requires Internet access.
The preview requires Microsoft Edge WebView2 Runtime. If missing, install it
from Microsoft's official page, then reopen the launcher:
https://developer.microsoft.com/microsoft-edge/webview2/
Runtime installation is not automated. .NET is already bundled.

IMAGES: PNG/JPEG, <=8 MiB each, <=4096 px per side, <=16 million pixels.
Imports become static PNG without original metadata. Use assets you may share.
FONTS: static TTF/OTF <=2 MiB, license TXT <=64,000 bytes, editable embedding
and redistribution rights required. Restricted fonts, variable fonts, font
collections and imported WOFF/WOFF2 are rejected. Bundled fonts include notices.
CONFIGURATIONS: .dtheme, <=24 MiB, selected assets embedded with SHA-256.
Compatible CSS imports include original source/provenance and validated edits,
rechecked on reopen/apply. Scripts and arbitrary resources are refused. See
CSS-IMPORT-COMPATIBILITY.md. Original CSS export retains exact source bytes;
it may be global when installed directly elsewhere. Share .dtheme for the
server-targeted workflow. Review the target before
applying a file from someone else. A checksum is not a publisher signature.

Backups: %LOCALAPPDATA%\PrimeBuild\DiscordThemeLauncher\backups
Last saved/applied configuration: same parent folder, last-configuration.dtheme
Themes: %APPDATA%\Vencord\themes
Managed filenames: PrimeBuild.theme.css, PrimeBuildDev.theme.css,
FantaFort.theme.css, PersonalServer.theme.css

MANUAL RECOVERY: Fully quit Discord, move only affected managed CSS files out
of Themes, then reopen. Do not delete entire Discord/Vencord data folders.
Restoration does not uninstall Vencord. Old three-file backups remain usable.

Windows x64 / standard per-user stable Discord / default Vencord only.
No service or auto-start. The preview uses a temporary isolated WebView2 cache;
it blocks external navigation and document network requests.

The executable is UNSIGNED. Review source and checksums before running it.
No protection or Windows warning is bypassed. Vencord is unofficial and has
Discord terms/account implications. FantaFort is independent of Epic Games.
